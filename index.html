Projeto acadêmico

COLIV

Plataforma que conecta estudantes que querem dividir moradia. Pensada como um monolito modular, para manter o código organizado sem a complexidade de microsserviços logo de início.

  • Webhook: integração com AbacatePay para cobranças via Pix.
  • Arquitetura em módulos: regras de negócio separadas por domínio.
  • Full stack de ponta a ponta: API em Spring Boot e interface em Angular.
